# Third-party components

CoC Auto uses the PolyForm Noncommercial License 1.0.0. The release includes
the project LICENSE file and its Required Notice.

CoC Auto includes Python, NumPy, OpenCV, websockets, and the PyInstaller bootloader.
Their notices are retained by the build; Python's license is included in the release.

The OCR runtime uses Tesseract 5.5.0 and its dependencies from conda-forge.
Exact package URLs, versions, and SHA-256 checksums are in `ocr/sources.json`.
Package license files are retained under `ocr/licenses/`.
Tesseract and the English/Indonesian tessdata_fast 4.1.0 models use Apache-2.0.
The models come from https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0.

Dashboard game artwork belongs to Supercell. Existing artwork source manifests
and font notices remain alongside the bundled dashboard assets.
