# Contributing

Start with the [development guide](docs/developer/development.md).

- Put Python application code in `src/coc_auto`, browser code in `web`, and tests in `tests`.
- Keep user settings and runtime data out of commits and release artifacts.
- Preserve both English and Indonesian text when changing the interface or logs.
- Run the Python and browser tests before submitting a change.
- Keep file moves separate from behavior changes where practical.

See [architecture](docs/developer/architecture.md) and
[Windows packaging](packaging/README.md) for implementation details.
